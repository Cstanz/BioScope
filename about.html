About BioScope

Belajar klasifikasi dengan alasan, bukan hafalan.

BioScope adalah prototipe pembelajaran biologi yang menggabungkan pengantar konsep, halaman ensiklopedia, tantangan klasifikasi, quiz, dan progress lokal.

Design principles

Scientific, editorial, restrained.

Antarmuka menggunakan HTML, CSS, dan JavaScript vanilla. Tidak ada backend, login, leaderboard, pencarian, chatbot, atau library UI eksternal. State pembelajaran disimpan di localStorage browser.

Placeholder visual disiapkan agar gambar biologis nyata dapat ditambahkan kemudian tanpa mengganti konten HTML.
