About BioScope

Belajar klasifikasi dengan alasan, bukan hafalan.

BioScope adalah prototipe pembelajaran biologi yang menggabungkan pengantar konsep, halaman ensiklopedia, tantangan klasifikasi, quiz, dan progress lokal.

BioScope dikembangkan sebagai antarmuka statis tanpa backend, login, maupun database eksternal. Seluruh progres belajar disimpan langsung di localStorage browser pengguna.

Frontend HTML5, CSS3, Vanilla JavaScript Tanpa framework atau library UI eksternal.
